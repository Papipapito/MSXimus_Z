# Atribución y procedencia (GPLv3)

Este repositorio (el **MSXimus Z**) es una **obra derivada** de:

- **MSXimus** — https://github.com/Papipapito/MSXimus. El repositorio de la Zynq nace como clon en el commit `bc6997c` (14/09/2026); desde entonces los dos árboles van por separado.
- y, a través de él, **MSXnano** — https://github.com/Papipapito/MSXnano
  - Rama base: `dev`
  - Commit base: `390132d061f14dbc6072bb20d1dbcce7012bd525` ("docs: diseño de frontend grafico…", tip de `dev`; RTL idéntico a `eaa8ac4` = F1 de limpieza pre-port)
  - Licencia: **GNU GPL v3**

Al ser derivado de código GPLv3, **este proyecto es GPLv3** y conserva los avisos de copyright y atribución de todo el código heredado. Al distribuir el bitstream o el código habrá que acompañar el fuente correspondiente. Condición heredada del V9968 de HRA!: el proyecto se puede publicar gratis y redistribuir con sus avisos, pero **no vender**.

El código de terceros que se descarga al compilar (TinyUSB, Mbed TLS, minimp3) **no se versiona**: `fpga/zynq/arm/get_tinyusb.sh`, `get_mbedtls.sh` y `get_minimp3.sh` lo traen en la versión fijada.
